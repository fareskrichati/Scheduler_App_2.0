How to find your Canvas calendar feed
  1. Open your school’s Canvas website in a browser and sign in.
  2. Select Calendar in the Canvas navigation.
  3. Select Calendar Feed in the calendar sidebar. On a phone, try the browser’s desktop website view if the sidebar is hidden.
  4. Copy the full link ending in .ics and paste it into the calendar feed field.

Keep this link private. UniPlan lets you review dated assignments and exams before adding them.
